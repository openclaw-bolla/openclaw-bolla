Bei Profilen, mit denen Chris nicht direkt vernetzt ist (LinkedIn zeigt "2." o.ä.), gibt es zwei Buttons
mit unterschiedlichem Kostenverhalten (getestet 22.07.2026 an Yasemin Efiloğlu):

- **"Nachricht"** (Papierflieger-Icon, direkt sichtbar) → führt zur Premium-Probemonat-Aufforderung.
  NICHT klicken, wenn kostenlos bleiben soll.
- **"Mehr"** (drei Punkte, daneben) → enthält **"Vernetzen"**, das kostenlose Vernetzungsanfrage mit
  optionalem Notizfeld öffnet. Das ist der Weg, den Chris nutzen will (siehe
  [[project_aurora_marketing_historie]] Runde 2, AURORA-Outreach).

**⚠️ Zeichenlimit korrigiert (23.07.2026, von Chris live verifiziert):** Das Notizfeld akzeptiert nur
**200 Zeichen**, nicht 300 wie ursprünglich hier vermerkt. Entwürfe entsprechend kürzer planen.

**Vor der Vernetzungsanfrage lohnt sich ein Blick auf "Kontaktinformationen"** (Link unter dem Namen im
Profilkopf) — manche Profile geben dort eine öffentliche E-Mail-Adresse frei, die den ganzen
LinkedIn-Umweg erspart.

**Wichtig:** LinkedIn-Vernetzungsnotizen unterstützen KEINE klickbaren Links — jede URL erscheint als
reiner Text, den der Empfänger manuell eintippen müsste.

**Profilbild-Icon (eigenes, für Einstellungen/Menü) sitzt OBEN LINKS**, nicht oben rechts — von Chris
korrigiert 23.07.2026. Bei Klickpfad-Anleitungen entsprechend links verorten.
