# KDP Select — beim eBook-Publish NICHT aktivieren ⚠️

**KDP Select** = Amazons freiwilliges Exklusiv-Programm. 90 Tage eBook-Exklusivität bei Amazon im Tausch gegen Kindle Unlimited (Bezahlung pro gelesener Seite) + Aktionswerkzeuge (Gratis-Tage, Countdown-Rabatte).

- Exklusivität gilt **nur fürs eBook**, NICHT fürs Taschenbuch (Print darf überall verkauft werden).
- Verbietet jeden anderen eBook-Vertrieb: Apple Books, Kobo, Tolino, B&N — **und auch D2D**.

## Der Konflikt bei AURORA
AURORA-eBook wird **über D2D** an alle Nicht-Amazon-Shops verteilt (ISBNs siehe [[project-aurora-identifiers]]). Deshalb:

> 🔑 Beim eBook-Publish auf KDP das Häkchen **„KDP Select" NICHT setzen.** Sonst Verstoß gegen Exklusivität → Amazon kann das Buch sperren.

Chris' Strategie = breit verteilen (Amazon-eBook ohne Select + D2D überall) = maximale Reichweite. Bewusste Entscheidung gegen Amazon-Exklusiv.
