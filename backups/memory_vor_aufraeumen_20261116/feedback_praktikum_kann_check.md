Chris, 16.11.2026 (Kurstag 8): In Schritt 4/5 sollten Schüler Titel/Stichworte in Folien tippen — sie wissen aber noch nicht, wie man Text in einen PowerPoint-Platzhalter einfügt. „Praktikum immer prüfen, ob die Schüler die jeweilige Anweisung schon umsetzen können (hatten wir, glaube ich, schon vereinbart)“.

**Why:** Anweisungen, die Vorwissen voraussetzen, das nie unterrichtet wurde, blockieren Schüler.

**How to apply:** Pro Schritt gegen die Folien/Notizen der bisherigen Kurstage prüfen (python-Textsuche in `Handouts/0N-*.pptx`). Fehlende Fertigkeit → kurzer ✍️-Hinweis in grauer Box (nur Hinweis, siehe [[feedback_praktikum_nuetzliche_funktionen]]); Impress-Variante nicht extra erklären (Impress nur privat). Ergänzt [[feedback_praktikum_geraete_check]] (Geräte) um die Wissens-Seite.
