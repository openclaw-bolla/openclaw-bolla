Bei Problemen mit Online-Diensten (Outlook, Teams, Microsoft 365, Mail, Cloud-Dienste, Websites) immer ZUERST prüfen, ob das Problem beim Anbieter bzw. auf Servern im Internet liegt – erst danach an Gerät, Profil oder Konten herumdoktern.

**Why:** 13.11.2026: Outlook auf dem Studio „startete nicht" / hing. Ich habe über eine Stunde lokal gesucht (Prozesse, Profile, Registry, Icon-Cache, Explorer-Neustart). Ursache war eine Microsoft-Störung bei Outlook und Teams (Chris las es in der Tagesschau, danach ging alles wieder). Der lokale Aufwand war umsonst, teils mit Eingriffen (Prozesse beendet, Cache gelöscht, Konto entfernt).

**How to apply:** Vor jeder lokalen Diagnose: (1) Statusseite/Störungsmeldung des Anbieters prüfen (z. B. Microsoft 365 Service Health, Downdetector, WebSearch „Störung <Dienst> heute"), (2) prüfen, ob andere Geräte/Webzugang (outlook.office.com) betroffen sind, (3) erst wenn extern alles ok → lokal suchen. Chris das Ergebnis kurz nennen („Anbieter-Störung" oder „liegt bei uns"). Keine destruktiven lokalen Eingriffe (Konto entfernen, Cache löschen, Prozess killen) bevor die externe Prüfung gelaufen ist.
