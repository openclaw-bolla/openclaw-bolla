## Suno Songs Layout — Epische Debugsession

Langer Tag mit dem Suno-Songs-Layout in Mission Control.

**Root Cause gefunden:** `#page-suno` war außerhalb von `#app` → `#main` → `#pages` im HTML platziert. Dadurch hat sich die Seite relativ zum Viewport positioniert und die Sidebar überlagert. Alle anderen Seiten (Wetter, Bolla, Bildgen etc.) lagen korrekt innerhalb von `#pages`.

**Was wurde geändert:**
- `#page-suno` in die richtige Position innerhalb `#pages` verschoben
- Layout komplett neu: Formular oben in zentrierter Card (~65% Breite), darunter Zwei-Spalten-Grid für Ergebnis
- Links: Titel + Style Prompt + Verbessern-Box
- Rechts: Lyrics-Box (Heading jetzt innen wie bei Titel, 📋 kopiert nur Text)
- CSS: `#page-suno-output.visible { display: grid; grid-template-columns: 1fr 1fr; }` für das Ergebnis-Grid
- JS: `suno-result-grid` wird nach Generierung eingeblendet

**Nebenbefund:** Viele CSS-Änderungen schienen nicht zu greifen — lag aber daran dass die Seite wegen falscher Position immer noch die alte Ansicht zeigte. Kein Cloudflare-Cache-Problem.
