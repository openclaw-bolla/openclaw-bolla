## Was heute passiert ist

### Book-Akku — der echte Fix

Chris kam morgens mit einem neuen Symptom an: Book lief in der Schule normal auf Akku 2, aber beim Anstecken des Netzteils → **sofortiger Crash + 5–6 Min Totzeit am Einschaltknopf**. Anderes Symptom als das alte Schnellstart-Boot-Problem.

Per SSH ins Book Event-Log geschaut: **Event-ID 41 KRITISCH** („Stromzufuhr unerwartet unterbrochen") direkt nach Anstecken, gefolgt von **3× Event-ID 521** („Änderung der Anzahl aktiver Akkus") beim Reboot. Smoking Gun.

Ursache: Beim Anstecken enumeriert Windows beide Akkus → versucht Akku 1 zu erkennen/laden → defekter Akku (Voltage=0, Capacity=0xFFFFFFFF) crasht das Charging-IC.

Fix: Akku 1 in Windows deaktiviert via Admin-PowerShell:
```
Disable-PnpDevice -InstanceId "ACPI\PNP0C0A\1" -Confirm:$false
```

Verifiziert: Status=Error, Problem=CM_PROB_DISABLED. Win32_Battery zeigt nur noch einen Akku. Sofort-Test (Strom raus/rein am laufenden Book) bestanden — kein Crash.

**Reflexion** (von Chris angestoßen): Warum nicht schon vor 4 Wochen, als Akku 1 als defekt bekannt war? Antwort: Wir waren symptom-getrieben („Boot-Verzögerung → Schnellstart") statt hardware-getrieben („defekter Akku → was kann der alles auslösen?"). Lektion als Feedback-Memory gespeichert: [[hardware-defekt-proaktiv]]

### MC-Dashboard Redesign

Chris meldete vom Book: „Boxen NÄCHSTE TERMINE WETTER sind sehr schmal und der gesamte Seitenbereich ist auch abgeschnitten".

Diagnose: Dashboard nutzte ein 4-Spalten-Grid mit **fest verdrahteten** `grid-column`-Inline-Styles (Greeting auf 3/5, Wetter auf 3, Schule auf 4). Bei kleinen Viewports schaltete die Media Query das Grid auf 2 Spalten um — aber die Inline-Positionen blieben → Boxen ragten rechts raus.

Erste Iteration: 2-Spalten-Modus mit Reset der Inline-Positionen → besser, aber 4. Box rutschte in zweite Zeile, rechts Lücke.

Zweite Iteration (Chris' Idee): **Wetter in den Greeting-Banner integriert**, links Wetter, rechts Begrüßung. Greeting volle Breite oben. Drunter ein Auto-Fit-Grid mit 3 Boxen (Termine, E-Mail, Schule). Keine Lücken mehr, alles atmet responsiv. Schick.
