## Schul-PC: Fake-Virenwarnung nach dem Booten

Chris meldete morgens eine Viren-/Trojaner-Warnung auf einem Schul-PC (Lessing-Gymnasium), die direkt nach
dem Booten erscheint — noch vor jedem Browserstart. Erster Ansatz ging daneben (PowerShell-Diagnose auf
Chris' eigenem Surface statt dem Schul-Rechner), sofort korrigiert.

Ferndiagnose ergab: Edge-Verknüpfung sauber, Autostart-Ordner unauffällig, aber Klick auf die Warnung oder
Versuch sie zu schließen öffnet Edge mit einer sehr langen Tracking-URL. Verdacht: Scareware/PUA über einen
Scheduled Task oder ein Autostart-Programm, unabhängig von Edge selbst — typisch für einen gemeinsam
genutzten Schul-PC (Schüler-Download als Infektionsquelle).

Portables Diagnose+Fix-Tool gebaut: `D:\OneDrive\Desktop\SchulPC-Check\` (`schulpc_check.bat` + `.ps1`),
für den USB-Stick gedacht. Macht read-only Bericht über Scheduled Tasks, Autostart, Edge-Erweiterungen/
Benachrichtigungsrechte, kürzlich installierte Programme, Defender-Status — und fragt vor jedem Fix
einzeln nach (nichts wird blind verändert, alles reversibel: Tasks nur deaktiviert, Autostart-Dateien nur
in Quarantäne verschoben).

Betroffener PC: Nr. S9462 ("mekren"). Schul-IT-Kontakt für später: it@lg-n.de. Chris testet das Tool morgen
(27.08.) am Schul-PC vor Ort. Details: siehe Memory [[project_schulpc_scareware]].
