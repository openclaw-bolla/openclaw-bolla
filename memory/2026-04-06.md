## Mission Control CSS-Lehre (06.04.2026 Nachmittag)

### Das Problem (3+ Stunden Debugging!)
- Alle Pages außer Dashboard hingen unten statt oben
- Ursache: Pages waren normale `display:none/block` Elemente im Dokumentfluss
- Browser berechnete Gesamthöhe ALLER Pages (auch unsichtbarer) → aktive Page landete in der Mitte
- Dashboard funktionierte weil es die ERSTE Page war (kein Offset davor)

### Die Lösung
```css
.page {
  display: none;
  position: absolute;  /* ← DAS ist der Schlüssel */
  top: 0; left: 0; right: 0; bottom: 0;
  overflow-y: auto;
  padding: 20px 24px;
}
.page.active { display: block; }
```
`position: absolute` nimmt die Pages aus dem Dokumentfluss → kein gegenseitiger Einfluss → immer oben!

### Weitere Learnings
- Beim CSS-Flicken aufgehört, komplett neu geschrieben → sofort gelöst
- Bei mehreren Seiten die per display:none/block umgeschaltet werden: IMMER position:absolute!
- body::before mit SVG-Inhalt hatte z-index Probleme → besser vermeiden
- Terminologie: Sidebar / Pages / Cards
