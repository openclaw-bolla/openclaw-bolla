# Session 2026-05-06

## WISO Mein Geld — Adresslisten-Bereinigung

### Problem
- Chris' WISO-Adressliste hatte 3.431+ Einträge mit 129+ Duplikat-Gruppen
- WISO konnte Zahlungsempfänger nicht mehr automatisch erkennen/kategorisieren
- Vorherige Session: Script hatte irrtümlich "Löschen" statt "Zusammenführen" genutzt → WISO-Fehlerdialog 18x ignoriert → Chris musste abbrechen

### Lösung: wiso_cleanup.py (Desktop)
Script nutzt pywinauto + pyautogui zur UI-Automation von WISO Mein Geld Professional 365:
1. **Scan**: Alle Adressen per virtualem Scroll einlesen (Counter → Duplikate finden)
2. **Merge**: Für jeden Duplikat-Namen → Suchfeld per Clipboard befüllen → Panel neu laden → exakte Treffer per Ctrl+Click auswählen → Shift+F10 (Kontextmenü) → "Zusammenführen" → OK

### Technische Details
- WISO = WPF-App, DevExpress DataGrid, virtual scrolling (~28 Zeilen sichtbar von 3.400+)
- DataPanel-Referenz wird nach Suchfeld-Filter invalidiert → muss nach jeder Suche neu geholt werden
- `pyautogui.typewrite()` unterstützt kein Unicode → Clipboard via ctypes (mit explizitem `restype = c_void_p`!)
- Kontextmenü via `Shift+F10` (nicht Rechtsklick, der deselektiert)
- WISO-Suche ist Substring-basiert → exakter Match nötig: `rows = [r for r in rows if r['bez'] == name]`
- Ctrl+Click für Multi-Select (nicht Shift+Click, der wählt Zwischenzeilen mit)
