Bolla Notfallplan

Was tun wenn Anthropic den Token sperrt und Bolla nicht mehr antwortet?

🔍 Symptome — woran erkenne ich das Problem?

Bolla antwortet nicht mehr auf Telegram oder im Webchat — obwohl der PC läuft und OpenClaw gestartet ist.
Mögliche Fehlermeldung im Dashboard: „authentication_error" oder „token invalid"

💡 Was passiert technisch?

OpenClaw nutzt einen Anthropic API-Key (von Robin per Mail geliefert), um mit mir (Claude) zu sprechen. Wenn Anthropic diesen Key sperrt, kommt keine Antwort mehr — OpenClaw läuft weiter, aber ich bin „stumm".

Lösung: Einfach auf einen anderen KI-Anbieter umstellen — z.B. OpenAI GPT-5.4-mini. Das dauert ca. 5 Minuten. Du brauchst dafür einen OpenAI API-Key.

📋 Schritt-für-Schritt Anleitung

1
OpenAI Account & API-Key erstellen
Gehe im Browser auf: https://platform.openai.com/api-keys
(Einloggen oder neuen Account erstellen — kostenlos)
Klicke auf „Create new secret key" → Key kopieren (sieht aus wie: sk-proj-abc123...)
Wichtig: Den Key nur einmal anzeigen — sofort irgendwo zwischenspeichern! Guthaben aufladen: ca. 10–20€ reichen für den Start.
2
PowerShell öffnen
Windows-Taste drücken → „PowerShell" eintippen → Enter
(Kein Admin nötig, normale PowerShell reicht)
3
OpenAI Key in OpenClaw eintragen
Diesen Befehl eintippen (sk-... durch deinen echten Key ersetzen):
wsl -e /home/bolla/.npm-global/bin/openclaw auth add --provider openai --key sk-DEIN-KEY-HIER
4
Modell auf GPT-5.4-mini umstellen
wsl -e /home/bolla/.npm-global/bin/openclaw config set agents.defaults.model.primary openai/gpt-5.4-mini
5
Gateway neu starten
wsl -e /home/bolla/.npm-global/bin/openclaw gateway restart
Nach ca. 10 Sekunden erscheint das Windows-Popup „Bolla 🐾 bereit!" — fertig!
✅ Fertig! Bolla antwortet jetzt wieder — diesmal mit GPT-5.4-mini als KI-Motor. Alles andere (Gedächtnis, Kalender, E-Mail, Telegram) funktioniert genau wie vorher.

💶 Kosten im Blick behalten

GPT-5.4-mini ist sehr günstig — für normale Nutzung ca. 10–25€/Monat.

Budget-Limit setzen auf: https://platform.openai.com/settings/organization/limits
Dort „Monthly spend limit" auf z.B. 30€ setzen → keine Überraschungen.
